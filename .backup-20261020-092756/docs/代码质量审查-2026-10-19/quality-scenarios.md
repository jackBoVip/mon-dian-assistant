# 质量属性场景 — 蒙电信产助手（2026-10-19）

每条场景 = 刺激 → 期望响应 → 度量 → 取证方式。带"未测"的即审查中确认**目前没有测量手段**的项，也是 `remediation-plan.md` 里对应动作的验收判据来源。

## S1 性能 · 写命令的索引代价（对应 F9/F10/F19）

- **刺激**：10,000 条凭据的库，使用者执行一次"重命名一条凭据"。
- **期望响应**：写命令只更新受影响行，索引按该条目增量替换；命令返回前不得出现全库解密。
- **度量**：命令 P50/P95 延迟；单次写触发的 SQL 语句数与 `open_json` 调用数（应从 ~3N+N 降到 O(1)）。
- **取证**：`cd src-tauri && cargo bench`（入口 `tests/import_scale.rs`）；或临时计数 `can_access_item` 调用次数。
- **现状**：**未测**。审查只能确证结构（`state.rs:113-120` → `repo.rs:667-761` 每条凭据 3 相关子查询 + 1 次 AES-GCM 解密，7+ 处写命令调用），持锁范围覆盖整个重建。

## S2 响应性 · 重活不阻塞界面（对应 F10）

- **刺激**：解锁（双 Argon2id）、导入 64MB xlsx、下载更新、S1 的全量重建，任选其一进行中。
- **期望响应**：窗口可拖动、可滚动、动画继续；结果以事件/回包形式到达。
- **度量**：操作期间主窗 `requestAnimationFrame` 掉帧数；或"开始操作→界面首次无响应"的时间。
- **取证**：先确证 Tauri 2.12.3 同步命令的执行线程（读 `tauri-2.12.3/src/ipc/command.rs` 宏展开），再决定 `async` 还是 `spawn_blocking`。
- **现状**：**未测**，且**线程归属未证实**（只有"0 async / 0 spawn_blocking"是可证的代码事实）。

## S3 正确性 · 台账变更即时反映（对应 F5）

- **刺激**：在账号中心新建 / 改名 / 删除一个系统。
- **期望响应**：左栏系统列表在 mutation 成功后立即反映新数据；右栏账号列表与统计随之更新。
- **度量**：`targetsPaged` 与 `targets` 两族都被作废（组件测试断 `invalidateQueries` 入参）。
- **取证**：新增"取数键 ↔ 作废键"契约测试：枚举所有 `useQuery` 键 → 断言每键存在匹配的前缀。
- **现状**：**坏**。主列表用 `targetsPaged` 取数、全部作废走 `['targets']`（`AccountsPage.tsx:58` vs `:91`）。

## S4 安全/隐私 · 同一字段一个口径（对应 F2/F6/F7）

- **刺激**：一个只有 `accounts.read`、没有 `accounts.view_secret` 的使用者，尝试取得他人凭据的用户名/明文，或读取回收站列表。
- **期望响应**：① `copy_username` 被拒且不写剪贴板；② 切换字段/条目时迟到响应不得覆盖已清空的明文格；③ 回收站只列出该使用者可见的条目。
- **度量**：三条后端测试 + 一条前端"请求世代"测试（先发起 reveal、再切 `itemId`、断最终显示为空）。
- **取证**：`cargo test --lib`（新增用例）+ `npx vitest run src/components/accounts`。
- **现状**：①②③ 均**无守卫**，①③ 已确证口径不一致（`accounts.rs:38-55` vs `:460-473`；`repo.rs:1429-1441` 无可见性过滤）。

## S5 可诊断性 · 一次失败能定位（对应 F13/F14/F28/F31）

- **刺激**：备份写盘失败 / 更新清单 JSON 损坏 / release 界面报错无栈。
- **期望响应**：日志含底层原因（errno / 解析位置）；错误码不与真实原因相反；debug 产物有 sourcemap；主门禁的基线不可被静默替换。
- **度量**：`grep -c "map_err(|_| AppError::Internal)" src-tauri/src` 下降；`TAURI_ENV_DEBUG` 生效（`dist/assets/*.map` 非空）；篡改基线快照后 `globalCssEquivalence` 必须红。
- **现状**：三项**不合格**，其中基线完整性（`BASELINE.css.sha256` 无人校验）是唯一会让"布局一致"结论整体失效的一条。

## S6 可部署性 · 冷环境能出包（对应 F33）

- **刺激**：在一台只有源码的新机器上执行 `npm run tauri:build`（以及 x86_64 / Windows / Linux 目标）。
- **期望响应**：sidecar 由构建链产出，产物内 asset 表与 `dist` 缺失 0 / 陈旧 0。
- **度量**：`ls src-tauri/binaries` 覆盖每个 target triple；打包后按 `docs/交付状态与验收.md` §1-Z(f) 的 asset 表判据核对。
- **现状**：**只有** `mda_fill_host-aarch64-apple-darwin`，且 `beforeBuildCommand` 不构建 sidecar。

## S7 可维护性 · 惰性定义不累积（对应 F20/F16/F17/F18）

- **刺激**：新增一枚 shadcn 组件或删除一处界面（如再次换导航形态）。
- **期望响应**：不产生"定义了但没人引用"的令牌/类/组件/依赖；每条遗留都有登记表和 `why`。
- **度量**：产物 CSS 中"定义了但无 `var()` 引用"的自定义属性数（今天实测 **27**）、生产不可达类数（今天 **≈0**）、前端 0 引用的 npm/Rust 包数（今天 **2 / 疑似 3**）。
- **取证**：把本次审查用的两条脚本固化进测试（`remediation-plan.md` P2 #16/#14）。
- **现状**：类维度干净，令牌与依赖维度有累积。
